# 06 人物时间线

## 时间线

| 时间 | 事件 | 思维影响 |
|---|---|---|
| 1970s | 江南，本名杨治，安徽人。公开资料常称其毕业于北京大学化学系，后赴美国圣路易斯华盛顿大学留学。 | 理工背景强化结构、逻辑、世界观搭建；异乡经验催生自我表达。 |
| 2000 前后 | 留美期间写作《此间的少年》，以北大校园和武侠人物重构青春记忆。 | 确立“成长/少年/孤独/不被认同”的核心母题。 |
| 2005 左右 | 《九州缥缈录》出版并进入东方奇幻世界观写作。 | 从个人青春转向大体量世界观和英雄命运。 |
| 2006 | 《上海堡垒》创作，后来进入影视改编链条。 | 形成“类型外壳 + 情感核心”的写法。 |
| 2009-2010 | 《龙族》开始连载并出版。 | 建立现代奇幻、校园青春、孤独英雄叙事的代表性作品。 |
| 2013 | 凭《龙族》系列登顶作家富豪榜。 | 商业成功带来产业化机会，也带来“是否讨好读者”的质疑。 |
| 2016 | 成立北京灵龙文化发展有限公司，推动作品影视、漫画、游戏等开发。 | 从作家扩展为 IP 产业参与者，但公开警惕 IP 资本化。 |
| 2018 | 重启《龙族V：悼亡者的归来》连载，并与阅文集团合作。 | 承认读者期待巨大，强调“慢慢地写，慢慢地读”。 |
| 2019 | 《九州缥缈录》剧集、《上海堡垒》电影上线；江南谈创作瓶颈和抑郁前期状态。 | 影视化压力、写作体力下降、连载节奏冲突被公开化。 |
| 2021 | 《龙族III》修订版推出；公开资料称其逐渐恢复写作状态。 | 修订旧作、完善设定，继续强调语言和设定质量。 |
| 2026-04 | 知产力发布杨治专访，围绕《龙族》版权纠纷、仲裁、创作自由和作者权益发声。 | 创作问题与法律/产业环境绑定，作者尊严成为近期核心议题。 |
| 2026-05 | 中国知识产权报/中国知识产权资讯网等继续讨论江南与知音公司《龙族》纠纷的行业意义。 | 《龙族》不只是未完作品，也成为出版信任和作者权利案例。 |

## 最新动态（截至 2026-05-19）

- 《龙族5》公开状态：尚未完成最终出版定稿；江南仍表达完成意向，但受个人状态和版权纠纷影响。
- 版权纠纷：围绕知音公司超期加印、合同解除和仲裁问题，已有法院生效判决确认部分侵权事实；后续仲裁争议仍被媒体关注。
- 创作立场：近期公开表达从“我要写出国民级作品”进一步转向“保护创作自由、定稿权、作者人格尊严”。
