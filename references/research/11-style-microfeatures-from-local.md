# 11 本地语料：微观风格颗粒度

本文件基于用户提供的私有本地 `龙族全集.azw3` 与既有派生分析继续提炼。只保存统计、抽象规则和检查表；不保存正文、对白原句或可复刻片段。

## 轻量统计

- 文件类型：Mobipocket/AZW3，UTF-8，解码后可见字符约 409 万；由于未做完整 Palm/KF8 结构还原，以下统计仅作方向性校验。
- 可见非空片段约 2.45 万段，片段平均长度约 166 字；128 字以内片段约 70%，说明叙述常被短对白、动作、反应和场景切片打断。
- 标点密度显示逗号远多于句号，问号和感叹号都较高；适合表现迟疑、打断、吐槽、危机里的快速反应。
- 既有完整派生分析显示对白片段约 1.98 万条，短句和问句占比高；人物声音应优先靠短句、反问、沉默、动作和关系压力成立。

## Writer 级风格颗粒

### 1. 句式节奏：长句铺压力，短句做落点

- 中长句用于交代世界重量、关系前史、心理犹疑。
- 短句用于反应、否认、嘴硬、命令、危险确认。
- 一段里使用“铺垫句 -> 转折句 -> 短落点”，不要连续堆同一种长度。

失效信号：整段都是整齐的抒情句，读起来像文案，不像场景正在发生。

### 2. 叙述镜头：先给身体反应，再给意义

- 人物先有小动作、停顿、错看、找借口，再抽象出孤独、责任或命运。
- 大词必须落到小物件、小手续、小账单、小愿望或小狼狈上。
- 情绪不要直接命名三次以上；让读者从行为里判断。

失效信号：先说“他很孤独、很悲伤、很命运”，但现场没有任何可看见的动作。

### 3. 对白颗粒：信息句必须带关系动作

- 说明设定时，同时让说话人赢得地位、隐藏关心、试探忠诚或转移恐惧。
- 问句不是为了问答案，而是为了逼对方暴露立场。
- 玩笑不是装饰，应该承担缓冲、遮羞、攻击或救场功能。

失效信号：对白删掉角色名后像同一个人在讲 PPT。

### 4. 意象距离：保留机制，不复制表皮

- 可以使用“日常物件压住神话重量”的机制。
- 不要机械复用雨夜、孤独、命运、龙、学院、少年等表层符号。
- 原创任务优先换文化母体、入口载体和情感债形式，保持风格距离。

失效信号：看起来像换名版《龙族》开头，只有设定名词不同。

### 5. 改稿顺序：结构先于漂亮句子

1. 先确认本段非完成不可的转变。
2. 再删掉不改变关系的信息句。
3. 把剩余信息塞进冲突、玩笑、任务分配或误解。
4. 最后才调句长、停顿、比喻和收束。

## 输出前自检

生成小说方案、场景方案或改稿时，最后快速检查：

- 是否有一个具体低处，而不是抽象“废柴”？
- 是否有一个现实入口，而不是纯设定降临？
- 每段说明是否绑定了人物关系变化？
- 是否至少有一个小动作、小物件或小愿望承接大情绪？
- 是否避开近似仿写原文和表层符号堆砌？
